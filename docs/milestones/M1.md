# M1 — Template schema + renderer ✅

## `@sammly/template-schema`
- Zod schemas for the **Template Document v1** (brief §5): canvas, layers (`text`, `image`, `raster` with `clipping`, `shape`, `svg`, `imageSlot` with alpha/path/shape masks, recursive `group`), **fields** (8 types, bindings, constraints, brand sources, digits, AI allowance), **rules** (brand lock, AI policy + instructions, export sizes), meta, and `TemplateVariant` + standard sizes.
- `buildValuesSchema(fields)`: one values validator shared by the API and forms (required/optional, max length/lines, single-line text, select options, palette-restricted colors, phone, `YYYY-MM-DD` dates, number ranges, image values with crop; unknown keys rejected).
- `validateDocument` / `validateVariants`: publish checks (duplicate ids/keys, bindings to missing or incompatible layers, field-type vs binding, **unmapped fonts**, every variant defines every field key with the same type).
- `migrate(doc)` (version-stepped, v1 current) and `fromPocDesign()` to convert POC documents (direction detection, left/right → start/end, tracking dropped on Arabic, src → assetId).
- `pnpm --filter @sammly/template-schema build` writes `dist/schema.json` (JSON Schema for the mobile team).

## `@sammly/renderer-html`
- `buildRenderHtml(doc, values, { resolveAsset, resolveFont, mode, brand })` is a pure function. It applies values through the bindings (brand-kit fallback, locked brand fields, date formatting in hijri/gregorian/both, Arabic-Indic digits, select labels, `visible` bindings), embeds `@font-face` for every used library font, and emits layers.
- RTL: `dir` per layer, `unicode-bidi: plaintext`, alignment pinned by layer direction, no letter-spacing on Arabic.
- Image slots: cover/contain, user crop (focal point + zoom), circle/rounded/alpha-PNG/SVG-path masks, placeholder or empty colour; foreground layers above.
- Auto-fit script (shrink / wrap-shrink / maxLines) runs in the page; `window.__sammly = { done, overflow[] }` reports `TEXT_OVERFLOW` field keys.
- Export CSP: only `https://assets.local` and `data:` for images/fonts; the only script allowed is the nonce'd auto-fit.
- `@sammly/renderer-html/qa` (Node only): `renderPage()` (Playwright, routes `assets.local` to a loader and blocks all other network) and `compareImages()` (POC visual diff, buffer-based).

## Tests (37 in these two packages, all green)
- Schema: defaults, JSON round-trip, injection-safe colours, nested groups, values schema, publish checks, migrations, POC conversion.
- Renderer unit: determinism, RTL/bidi/alignment, font embedding, tracking rules, escaping, CSP, slot crop/masks, fit attributes, brand fill/lock, visibility, digits and dates.
- **Golden images** (Chromium, `test/golden/win32/`): wedding (circle-masked photo + frame, embedded Arabic font), Friday greeting (wrapped paragraph, hijri date in Arabic digits, star alpha mask, colour field), offer (mixed Arabic/Latin/digits, path mask, brand handle and phone), offer without phone (bound badge hidden), story variant; HD = 2× pixels.
- Auto-fit in the browser: keeps the designed size when it fits, shrinks long names, wraps then shrinks paragraphs within maxLines, reports overflow keys.
