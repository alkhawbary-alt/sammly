# M0 — Monorepo & infra ✅

**Built**
- pnpm 12 + Turborepo workspace: `apps/{api,worker,admin}`, `packages/{template-schema,renderer-html,importer-psd,shared,config}`.
- Docker-free dev mode (default): `pnpm dev` starts an embedded PostgreSQL (`.data/pg`, :5433), then the API (:4000), the worker health server (:4001) and the admin (:3000). `docker-compose.yml` (postgres/redis/minio) is used when `INFRA_MODE=docker`.
- API: Fastify with `/health`, `/ready` (DB check), `/api/v1/` and the shared error envelope.
- Worker: process shell with `/health` and `/ready` (queues land in M2/M4).
- Admin: Next.js 16, Arabic RTL by default with an English toggle (cookie), sidebar with the spec's navigation (unbuilt items shown as "قريباً"), API status card.
- `@sammly/shared`: error codes, plan codes/ranks, typed plan features.
- ESLint (flat config), strict TypeScript, Vitest, GitHub Actions workflow (`.github/workflows/ci.yml`).

**Acceptance:** `pnpm i && pnpm dev` starts everything (verified: `/ready` 200 on api and worker, admin renders RTL); `pnpm lint`, `pnpm typecheck` and `pnpm test` pass locally. CI hasn't run yet because the repo has no GitHub remote.
