## Built
- `@sammly/importer-psd`: Photoshop-compatible compositor (blend modes, special-eight fill opacity, masks, clipping, effects, adjustments, `.cube` LUTs) and the "bake below, live above" import model. Text conversion handles transform-derived size and rotation, baseline anchoring, logical justification (RTL verified), style runs, shadow/stroke/colour overlay, and fit defaults. Also: field suggestions from layer names, an import report (counts, per-layer status, warnings, missing fonts), composite extraction, and dev tools (`analyze`, `qa`, `sheet`).
- Schema/renderer additions: text `baseline`, `shadow`, `stroke`; `plus-lighter` blend.
- `@sammly/db`: full Prisma data model from brief §9 plus `Job`; initial migration.
- `@sammly/platform`: env config, storage (local signed URLs / S3-R2), assets with magic-byte sniffing, a Postgres job queue, and the font library (WOFF2 conversion, alias map).
- Worker: `import:psd` job (child process with memory cap and 60 s timeout → assets to storage → QA render and diff stored as assets, score on the ImportJob).
- API: upload presign, signed local storage, imports, jobs, and fonts CRUD; Zod validation; OpenAPI at `/api/v1/docs`.
- Seed: 19 open-licensed font faces (IBM Plex Sans Arabic ×8, Rubik, Baloo Bhaijaan 2, Cairo, Tajawal).

## Tests
Importer unit tests and a synthetic PSD (CI-safe); the real-fixture acceptance gate (skips without PSDs); API integration tests (skip without Postgres): oversize uploads, tampered tokens, magic-byte rejection, key/ID validation, 202 queueing, the font list, and non-font rejection.
