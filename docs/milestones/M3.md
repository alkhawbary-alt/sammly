# M3 — Admin: auth, categories, fonts, template editor ✅

## Acceptance (brief §15)
> Admin can log in, manage categories/fonts, import a PSD, tag fields, set constraints, test-fill live, validate, publish a version, duplicate a template, add a size variant, and use manual composition (bg/fg/mask).

| Item | How it was verified |
|---|---|
| Log in / out, silent refresh | Browser: login → dashboard. Tests: wrong password vs unknown email return the same 401, protected routes, cookie flags, rotation + reuse revocation, logout, SUPPORT read-only |
| Categories | Page with tree, add/edit/delete, reorder; seeded tree from §9 (+ تعازي) |
| Fonts | Page with real-font samples per weight, upload (TTF/OTF → WOFF2), aliases add/remove; "map font" in the editor adds the PSD name as an alias |
| Import a PSD | "Import PSD" dialog (upload progress → worker import → report with render/original/diff and QA score → open in editor); API script `scripts/e2e-import.ts` |
| Tag fields + constraints | Browser: accepted the `zone:photo` and `field:groom_name` suggestions → image slot + required text field; field editor with type-specific constraints, brand source, digits, AI allowance, multi-layer bindings |
| Test-fill live | Browser: typing a long name updates the preview; auto-fit shrinks it |
| Test render | Browser: real worker render, **165 ms**, PNG shown with overflow warnings |
| Validate / publish | Browser: validate → "ready", publish → v1, status published. Test: blocked with clear problems until a field + category exist |
| Duplicate template | Test: copy is DRAFT "(نسخة)" with both variants, assets shared |
| Add size variant | Browser: Square → Story (scaled + centred, same fields). "Import a PSD for this size" also available |
| Manual composition | Editor "Add layer": background / foreground (image upload), image slot, text box; slot masks: circle, rounded, **PNG alpha mask upload**, SVG path; drag/resize on canvas. Test: image ingest (EXIF orientation, metadata stripped, non-images refused) |

## Built
- **API:** admin auth (`/admin/auth/*`), RBAC guard, dashboard stats, categories CRUD + reorder, the template lifecycle (list/filter, create from import or manual, draft get/put with revision, meta patch, variants from import or duplicate-as-size, validate, publish → immutable version, unpublish, duplicate, versions, access list, test render, soft delete), image assets, and a `render:test` worker job.
- **Seed:** admin user (`ADMIN_SEED_EMAIL` / `ADMIN_SEED_PASSWORD`), 3 plans with typed features, 21 categories, 19 fonts.
- **Admin website (Arabic RTL, English toggle):** login, dashboard, categories, fonts, templates list (filters, thumbnails, status/QA badges), new-from-PSD and manual dialogs, and the **template editor**:
  - layer tree (Photoshop order; field / image / missing-font badges; visibility and lock toggles)
  - canvas: the real renderer in an iframe, zoom/fit, rulers, selection, hit-testing, drag/resize for manual layers, "original" and 50% overlay comparison with the PSD composite
  - variant tabs and add-size menu
  - inspector tabs: Layer (geometry, text, font mapping/upload, fit, slot masks/placeholder, convert-to-slot, delete), Fields (suggestions, make/bind, full field editor, ordering), Form & test (the generated end-user form, live values, validation messages, worker test render SD/HD), Settings (title, category, tags, plan, visibility, activity targeting, brand lock, AI policy + instructions, export sizes)
  - top bar: autosave state, import report, versions, duplicate, validate, publish.
- `FieldForm` (the generated form) is shared and will be reused by the customer simulator (M5).
